# Sport Manager Web Application Project

This is a final exam project for the course of "Web Application Programming". It is a full-stack React and Node.js application for managing amateur sports tournaments and field bookings. The system is fully containerized using Docker for "one-command" deployment and includes an automatic database seeder for demo data.

All source code, setup instructions, and the complete Docker architecture are located in the main repository.

**View the Full Project here:** https://github.com/loanmir/WebApp_Sport_App.
