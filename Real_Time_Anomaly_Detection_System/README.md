# Real-Time Cyber Anomaly Detection System

## Project Overview
This project was a group effort by Francesca Craievich, **Lucas Jakin**, and Francesco Rumiz for the Data-Driven Systems university course.

The main goal wasn't just to build a technical tool, but to learn how to work together as a professional team. We focused on creating a data-driven system that can spot security threats in network traffic and show them on a live dashboard. The project has an academic purpose.

## Team-work
To make sure we worked efficiently, we followed the SCRUM methodology. This helped us organize our tasks and stay on track through the following steps:
  - **Sprints:** We broke the project into small "Sprints" (cycles) lasting 1-2 weeks.
  - **Team Meetings:** We held regular meetings to plan our next steps, review what we finished, and talk about how we could work better together.
  - **Daily Syncs:** We stayed in constant contact via Microsoft Teams and WhatsApp to solve problems quickly.
  - **Task Tracking:** We used GitHub Issues and a Trello board to assign specific jobs to each person so everyone knew their responsibilities.


Working in a group taught us how to handle a real-world software development lifecycle:
  - **Code Reviews:** Before any new code was added to the final version, another team member had to review it to check for mistakes.
  - **Automated Testing:** We created 116 automated tests. These ran automatically every time we made a change to ensure we didn't break the system.
  - **Documentation:** We learned that writing down how the system works is just as important as the code itself. We created three main guides covering the technical setup, the project plan, and team rules.
